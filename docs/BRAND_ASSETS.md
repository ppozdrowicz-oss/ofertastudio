# Logotypy kanałów sprzedaży

Sekcja „Twój produkt. W każdym kanale.” korzysta z oryginalnych logotypów zapisanych lokalnie w `public/ofertastudio/assets`.

| Plik          | Oficjalne źródło                                                                                                                                          |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `allegro.svg` | [Logo z serwisu Allegro](https://about.allegro.eu/wp-content/uploads/2025/12/logo.svg), używane w nagłówku [about.allegro.eu](https://about.allegro.eu/). |
| `olx.svg`     | [Logo OLX](https://www.olxgroup.com/content/uploads/2023/01/OLX_Logo1.svg), wskazane dla marki OLX na [stronie OLX Group](https://www.olxgroup.com/).     |
| `shoper.svg`  | Oryginalny element SVG „Shoper Logo” z nagłówka [serwisu inwestorskiego Shoper](https://investors.shoper.pl/).                                            |

Pobrano 8 września 2026 r. Zachowano oryginalne ścieżki, kolory oraz pola `viewBox`, w tym odstępy wewnątrz pliku OLX. CSS zmienia wyłącznie rozmiar wyświetlania z zachowaniem proporcji. Każdy obraz ma tekst alternatywny z nazwą marki. Na ekranach do 480 px kanały tworzą dwie kolumny.

Logotypy identyfikują kanały sprzedaży wymienione w ofercie; sekcja nie zawiera deklaracji partnerstwa ani certyfikacji. Prawa do znaków należą do ich właścicieli.
