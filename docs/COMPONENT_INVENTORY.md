# Inwentarz komponentów OfertaStudio

## Statusy

- **Gotowy** — produkcyjny komponent objęty stroną `/design-system` i kontrolą jakości.
- **Wewnętrzny** — element pomocniczy, który nie stanowi samodzielnego publicznego API.
- **Planowany** — kontrakt jeszcze nie istnieje; nie dodajemy pustego pliku.

## Elementy świadomie nieutworzone

- `Metric` — brak potwierdzonych danych liczbowych.
- `Quote` — brak zatwierdzonych opinii.
- `ProjectCard` — tablica realizacji pozostaje pusta.
- `AudienceCard` — nie ma jeszcze drugiego realnego konsumenta poza przyszłym homepage.
- pełne komponenty headera, megamenu i menu mobilnego — zakres etapu 4.

Nie tworzymy tych plików do czasu pojawienia się prawdziwych danych lub widoku.
