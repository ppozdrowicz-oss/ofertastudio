# Zasoby graficzne

Zatwierdzone pliki statyczne należy umieszczać w katalogach `brand`, `services`, `projects` lub `placeholders` zgodnie z ich znaczeniem. Nazwy plików powinny być opisowe, zapisane małymi literami z łącznikami i nie mogą zawierać danych wrażliwych.

Na etapie 1 katalogi pozostają bez grafik: nie dodajemy tymczasowego logo, przypadkowych zdjęć ani generycznych placeholderów.
